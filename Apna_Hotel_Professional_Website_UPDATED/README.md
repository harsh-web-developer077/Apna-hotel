# Apna Hotel — Professional Static Website

A responsive multi-page restaurant website built with HTML, CSS and vanilla JavaScript.

## Pages
- Home
- Menu
- About
- Gallery
- Contact
- Reservation
- Privacy Policy
- Terms & Conditions

## Included
- Responsive navigation
- Mobile menu
- Reservation form interaction
- SEO meta descriptions
- `sitemap.xml`
- `robots.txt`
- Favicon
- Professional restaurant styling
- Image-backed hero, menu and gallery sections

## Before publishing
1. Replace `https://www.example.com` in `sitemap.xml` and `robots.txt` with your real domain.
2. Replace sample address, phone, email and menu prices with verified restaurant details.
3. For a production booking system, connect the reservation form to a secure backend/database.
4. The photos currently use remote Unsplash URLs, so internet access is required for those images.
